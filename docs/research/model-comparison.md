# 전체 게임 학습 모델 비교

2026-09-27. 사용자가 권장 주력 구조인 공유 화면 인코더 + GRU + PPO를 채택했다. [채택 결정과 데이터 재사용 경계](../decisions/0006-recurrent-ppo-and-replay.md). 학습 완료·게임 실력 향상은 별도 검증 대상이다.
중요 설계 검토: gpt-6-astra / ultra. 기존 [ADR 0004](../decisions/0004-local-state-and-self-evaluation.md)의 로컬 실행·관측 출처·독립 평가 경계를 유지한다.

## 현재 구현과 목표

기존 기준선은 선형 softmax + REINFORCE다. 새 공유 CNN+GRU 모델은 기존 화면 1,939장으로 시각 사전학습을 수행했고, 실제 전투에서 수집한 44개 전이로 PPO 가중치 갱신·저장·재로드를 통과했다. 실력 향상은 아직 검증하지 않았다. [실제 측정과 실행 경계](../guides/local-neural-learning.md).

메뉴 인식용 작은 분류기는 별도 지도학습 모델이다. 현재 실게임 실험의 규칙 기반 성장 선택·상점 갱신은 전체 게임 전략 학습이 아니다. 나무 식별·파괴·드랍·획득을 연결하는 검증 경로도 아직 없다.

목표는 적 접촉·적 투사체를 피하고, 강화 방법을 스스로 찾는 것이다. 캐릭터 선택부터 해당 판의 최종 종료까지 관측·행동·적용 결과를 연결하고, 전투·무기·성장·구매 선택이 장기 성과를 통해 개선되는 로컬 프로그램을 만든다. 에이전트 없이 플레이·수집·학습·평가가 실행되어야 한다. 한 웨이브·녹화 구간·학습 작업이 끝났다고 한 판이 끝난 것으로 취급하지 않는다.

## 권장 논의안

채택한 주력 구조는 **공유 화면 인코더 + GRU 시간 기억 + 단계별 행동 출력 + PPO**다. 신경망 코어와 제한된 전투 학습을 구현했다. 이동·후보 선택이 같은 현재 빌드와 판의 기억을 사용하되, 메뉴 종류별로 가능한 행동만 출력한다. 캐릭터·무기·성장·구매·건너뛰기 전체를 이 구조에 연결하는 작업과 독립 성능 평가가 남아 있다.

화면 글자/OCR·아이콘·숫자·장비 상태는 출처·시각·unknown 표시를 갖는 보조 관측이다. OCR은 이미지 속 글자를 문자열로 바꾸는 기능이며, 글자를 읽었다고 효과를 이해했거나 가중치가 학습된 것은 아니다. 능력치 숫자가 오른 것과 정책 실력이 오른 것도 별도로 평가한다.

나무는 화면에서 객체와 변화의 특징을 학습하고 장기 성과에 따른 행동을 학습할 수 있는 대상이다. 단, 현재 검출되지 않는 나무에 보상을 임의로 주지 않는다. 객체 추적·파괴·드랍·획득의 검증과 보상 중복 방지 또는 더 일반적인 시각 표현 학습을 비교한다. 모든 게임 지식을 몇 판 만에 습득한다는 보장은 없다.

후보별 의미 특징과 현재 빌드를 결합할 때 단순 선형 `state + candidate` 점수는 후보 공통 state 항이 softmax에서 상쇄된다. 비교용 작은 정책에도 교차 특징이 필요하며, 주력 신경망에는 공유 상태와 후보의 상호작용을 표현해야 한다.

현재 확인 장비는 Ryzen 5 3600XT, RAM 약 32 GiB, GTX 1660 SUPER 6144 MiB VRAM이다. 작은 재귀 PPO부터 자원·처리량을 측정하고 DreamerV3를 같은 정보 조건의 후속 비교군으로 둔다. 이는 장비 제약에 따른 설계 판단이며 학습 성공/속도 보장이 아니다.

## 속도·기억과 학습의 분리

알려진 메뉴의 이름·위치·화면 서명을 저장하면 매번 재탐색할 필요가 없다. 현재 배치와 포커스를 최신 화면으로 확인한 뒤 이동한다. 메뉴 기억은 가중치 학습과 별개이고, 신규 해금·배치 변화·언어·해상도 변경 때 재검증해야 한다.

고정 2초 대기를 목표로 삼지 않는다. 기존 2.5초는 입력용 관측 만료 기준이다. 최종 읽기 전용 측정에서 기존 두 번 캡처+80ms 방식 중앙값 675.9ms, 상주 작업자 방식 205.0ms였다. 새 방식도 요청 이후 두 프레임을 확인하되 프로세스 재실행과 첫 프레임 PNG 저장을 제거하고 무손실 PNG 압축 수준을 낮춘다. 기존 3회·신규 예열 제외 5회, 실행 중 게임의 서로 다른 화면/부하에서 측정했으므로 고정 배속 향상을 보장하지 않는다. 전체 선택 지연이나 학습 성능 개선 수치도 아니다. 증거는 로컬 artifacts/menu-capture-benchmark/report.json이며 공개 데이터에 포함하지 않는다.

## 자체 검증과 모델 교체

정책이 예상한 성공률을 정답으로 쓰지 않는다. 관측 실패·중단·사망·목표 달성을 구분하고, 입력 전송과 실제 적용 증거를 분리한다. 자기 행동은 RL 경험이지 BC 정답이 아니다.

전체 판의 모델 버전·데이터 manifest를 고정한다. 후보와 기존 모델을 동일 캐릭터·난이도 조건의 별도 판에서 비교하고, 학습에 쓰지 않은 평가 기록으로 승격 여부를 결정한다. 시드 고정이 지원되지 않으면 같은 시드 비교를 주장하지 않는다. 오류율·진행도·승률·지연·자원 사용을 같이 보고하며, 결과 표본이 부족하면 보류한다. 한두 번의 승리나 가중치 변경만으로 개선을 선언하지 않는다.

GitHub에는 코드·재현 설정·검사·모델 설명을 준비한다. 모델 가중치를 공개할 때는 학습 출처·허용 범위·검증 결과와 배포 방법을 별도로 정한다. 게임 파일·세이브·원본 영상·민감정보를 저장소에 넣지 않는다.
