# PlayModel 학습 목적

PlayModel은 게임을 스스로 조작하고, 경험을 수집하고, 로컬 모델을 반복 학습하는 연구 프로그램이다. 목표는 모든 장르의 게임 QA 자동화, 자동 플레이를 통한 활용성 검토, 장기적으로 인간 행동 학습이다. 첫 검증 환경은 Windows Steam의 Brotato이며, 첫 게임의 결과를 다른 장르의 성능으로 일반화하지 않는다.

## 목표

- **게임 QA 자동화:** 메뉴부터 실제 플레이·성장·결과·재시작까지 반복하고, 정지·오류·비정상 전이를 재현 가능한 로그와 영상으로 남긴다. 플레이 정책과 결함 판정 기준은 구분한다. 현재 모든 게임의 결함을 자동 판별하는 도구는 아니다.
- **자동 플레이를 통한 활용성 검토:** 진행 가능성, 선택 과정의 마찰, 행동별 결과, 빌드와 난이도에 따른 차이를 평가한다. 자동 플레이 기록만으로 사람의 재미나 사용성을 입증하지 않는다.
- **인간 행동 학습:** 장기적으로 동의받은 사람 시연·교정을 활용해 선택·적응·행동 차이를 연구한다. 게임 정책 학습이 곧 인간 행동 전체를 이해했다는 뜻은 아니다. 사람 자료는 현재 자율 실행의 필수 조건이 아니다.

## 반복 자체 학습의 원칙

정상 실행 경로는 외부 LLM이나 유료 API를 요구하지 않는다. 게임 플레이와 경험 수집은 로컬 추론 프로그램이 수행하고, 별도 학습 작업자가 검증된 경험으로 후보 모델을 갱신하는 구조를 목표로 한다. 개발용 에이전트는 구현·오류 수정에 사용하며 게임의 매 행동을 대신 선택하지 않는다.

플레이 중인 모델은 고정한다. 후보는 별도 파일로 저장하고 판 경계에서 평가·교체한다. 학습 작업이 실시간 입력을 방해하지 않도록 자원 사용량과 지연을 기록한다. 단순히 게임 실행 횟수가 늘었다고 학습이 진행됐다고 보고하지 않는다. 학습 manifest, 원정책 버전, optimizer 갱신, 후보 체크포인트, 평가 결과가 증거다.

현재 PPO는 같은 원정책에서 수집한 자료를 제한된 epoch로 재사용한다. 오래된 정책의 행동이나 AI 자기 출력을 사람 정답으로 취급하지 않는다. 평가 자료는 학습과 분리한다. 향후 평가 자료를 학습으로 전환할 경우 원본을 보존하고, 해당 모델 계보에는 새 독립 평가 자료를 사용해야 한다.

## 현재 구현과 미완료 범위

현재 모델은 CNN+GRU와 단계별 행동 출력, PPO를 사용한다. 실제 전투와 성장·상점 선택을 기록하고 학습판·기준 모델 평가판·후보 모델 평가판을 완료했다. 현재 보상은 주로 wave 완료와 사망에 연결된다. 캐릭터·시작 무기·최고 난이도 설정에는 초기 규칙이 남아 있다.

HP 감소 원인, 접촉과 투사체의 구분, 회복 아이템 위치, 나무 파괴의 이득, 경험치·처치·장기 빌드 효과를 충분히 이해하고 학습했다고 검증하지 않았다. 승리나 최적 빌드를 보장하지 않는다. 플레이 도중 별도 작업자의 반복 학습은 구현·실측 대상이며, 단순 실행 중 상태와 실제 최적화 중첩을 구분한다.

사용자가 제시한 Pluto와의 공통 지향점은 경험을 통해 반복 발전하는 자율 학습이다. 동일한 모델 구조·학습 규모·성능을 구현했다고 주장하지 않는다. [모델 비교](research/model-comparison.md), [학습 커리큘럼](guides/learning-curriculum.html), [수동 실행 가이드](guides/standalone-learning.html)를 함께 참조한다.
