# Brotato 학습 녹화·편집·녹음

현재 사용자 요구: **전투·성장·상점·대기·실패를 포함한 학습 세션 전 과정**을 OBS로 녹화한다. 이전의 전투/레벨업만 녹화 조건을 대체한다. 게임 언어는 영어, 설명 자막은 한국어. 업로드는 별도 작업이다.

## 실행

1. Brotato를 켜고 언어를 English로 설정한다. 현재 메뉴 캘리브레이션은 1920×1080이다. 실행 중 언어를 바꾸면 이미 생성된 카드 문구가 이전 언어로 남을 수 있다. 다음 화면 생성 후 확인한다.
2. OBS에서 WebSocket 서버를 활성화한다. 프로그램은 로컬 설정의 비밀번호로 `127.0.0.1`에 접속한다. 비밀번호를 코드·Git·로그에 넣지 않는다.
3. OBS 장면 `PlayModel - Brotato`, 소스 `PlayModel - Brotato Game`을 사용한다. 소스 종류는 게임 캡처, 특정 창 `Brotato:Engine:Brotato.exe`, 게임 오디오 캡처 활성화. 화면 전체 캡처는 이 장면에 넣지 않는다. 현재 컴퓨터에는 이 장면이 구성돼 있다.
4. `scripts/start_brotato_recorded.pyw`를 실행하면 콘솔 없이 시작한다(Windows Python 파일 연결 필요). 또는 현재 컴퓨터에서 `scripts/run_brotato_recorded.ps1` 실행. 기본 2개 전투 구간, 최대 180초. Python 진입점은 `scripts/run_brotato_session.py --record --waves 2 --seconds 180`이다. FFmpeg 편집은 세션 종료 후 수행한다.
5. F8 또는 `artifacts/BROTATO_STOP` 파일로 중지한다. 중지 파일은 자동 삭제하지 않는다. 재실행할 때 사용자가 파일을 제거해야 한다.

현재 런처는 이미 검증된 레벨업·상점·일시정지·전투 화면에서 이어 진행한다. 시작 메뉴·모든 캐릭터·결과 화면 재시작까지 완성된 범용 플레이어는 아니다. 인식 불가 상태는 제한된 재관찰 후 `help-request.json`으로 남긴다. 자동 에이전트 호출은 없다.

실행 중 마이크와 전체 데스크톱 오디오는 일시 음소거, 종료 후 기존 상태 복원. 게임 소리는 게임 캡처 소스를 통해 받는다. 다른 수동 녹화/방송이 이미 진행 중이면 자동 녹화는 시작하지 않는다. 게임 입력은 HWND 키보드 전송이며 물리 마우스·전경 창을 옮기지 않는다.

## 결과

`media/captures/<세션>/`:

- `original/`: OBS 원본. 편집으로 덮어쓰거나 삭제하지 않는다.
- `highlights.mp4`: 주요 사건 전후를 이어 붙인 자막 없는 편집본.
- `highlights.ko.srt`: 편집본용 한국어 상황 설명. 영상에 굽지 않는다.
- `full-session.ko.srt`: 전체 원본 시간축 설명.
- `narration.ko.md`: 편집본 시간코드와 녹음용 설명.
- `preview.html`: 로컬 영상 미리보기와 자막 켜기/끄기. 영상과 같은 폴더에 둔다.
- `recording.json`: 녹화 시간축·사건·상태. `edit.json`: 원본 검사와 컷 구간.

영상 편집기에 MP4와 SRT를 함께 가져와 설명을 보며 녹음한다. 녹음 후 자막 트랙을 끄거나 제거한다. 최종 출력에 자막을 넣지 않으면 영상에서 사라진다. 원본/SRT는 보관해도 된다.

편집 기준은 학습 프로그램의 사건 기록이다. 전투 시작, 상점 갱신, 카드 선택 입력, 종료, 실제 가중치 갱신 주변 구간을 선택한다. LLM·음성 인식·외부 API 없이 작동한다. 생존 위기나 멋진 장면을 이해하는 영상 모델은 아직 없다. 원본으로 컷 누락을 검토해야 한다. 확인하지 않은 승리·능력 향상·해금·피격 원인을 자막으로 단정하지 않는다.

OBS 녹화 시간과 QPC 사건 시간을 연결하며 시작 요청/확인 지연을 기록한다. 프레임 단위 완벽한 자막 동기화는 보장하지 않는다. MP4 최종화를 확인한 뒤 FFmpeg 편집을 시작한다.

별도의 숨김 감시 프로세스가 학습 프로세스 종료와 녹화 제한 시간을 감시한다. 학습 프로세스가 비정상 종료해도 세션과 녹화 시간이 일치하는 자신 소유의 녹화만 종료하고 `guardian-recovery.json`을 남긴다. 복구 녹화는 자동 편집을 완료했다고 가정하지 않는다.

## 스타일·학습

`configs/styles/balanced.json`, `configs/styles/offensive.json`에서 능력치별 가중치, 회피 거리, 상점 갱신 횟수/보존 재료/예산 비율을 수정한다. 예: `scripts/run_brotato_recorded.ps1 -Style configs/styles/offensive.json`.

스타일은 현재 초기 선택 규칙과 이동 목표 생성의 설정이다. 학습으로 최적화된 빌드라고 부르지 않는다. 상점 갱신은 두 번 일치한 숫자 관측, 비용 제한, 실행 후 재료 차감·상품 변화 확인을 거친다. `shop-learning.json`에 이전/이후 화면, 상품 원문, 능력치 원문, 소비, 다음 전투 결과 참조를 저장한다. 결과 연결만으로 갱신의 인과 효과를 정답 처리하지 않는다. 자동 구매는 아직 꺼져 있다.

실제 이동 가중치 갱신은 검증된 전투 종료와 동작 기록이 있을 때만 수행한다. 같은 스타일이면 `artifacts/brotato-sessions/latest-training-policy.json` 후보 체크포인트에서 다음 학습을 이어간다. 후보 재사용은 학습 연속성 목적이며 성능 검증/모델 승격이 아니다. 평가 완료 주장 금지.

## 의존성·근거

OBS 선택 의존성: `pip install -e '.[obs]'`. 로컬 FFmpeg/ffprobe가 PATH에 필요하다. Windows OCR은 설치된 `zh-Hans-CN` 엔진을 사용 중이며 영어 게임 문구도 관찰한다. 영어 전용 OCR 팩은 현재 설치돼 있지 않아 숫자·글자 누락 시 중단한다.

제어 프로토콜: [OBS WebSocket v5 공식 문서](https://github.com/obsproject/obs-websocket/blob/master/docs/generated/protocol.md). 게임 캡처 설정: [OBS win-capture 소스](https://github.com/obsproject/obs-studio/blob/master/plugins/win-capture/game-capture.c).
