# 지속 플레이와 백그라운드 학습

사용자 목표는 모든 캐릭터로 최고 난이도에서 무한 모드 최고 웨이브에 도전하는 것이다. **현재 설치본 1.1.15.4에서는 Nightmare가 Danger 5 위에 있다.** 실제 난이도 선택 화면에서 확인했다. 스테이지 완료와 판 종료를 분리한다. 20웨이브 이후 상점과 다음 웨이브 번호가 반복 관찰되면 완료 조건 충족을 기록하되, 죽기 전까지 현재 판을 계속한다. 최종 최고 기록은 미래의 도전으로 갱신될 수 있으므로 전체 학습 완료를 자동 선언하지 않는다.

사용자가 말하는 **한 사이클은 한 캐릭터 선택부터 그 판의 최종 승리·사망·정상 종료까지**다. 웨이브/스테이지 종료, 10웨이브 파일 구간 마감, 이동 가중치 1회 갱신은 사이클 완료가 아니다. 무한 모드에서는 20웨이브를 넘겨도 같은 캐릭터의 판을 계속한다. 학습 코드의 전투 `episode`는 현재 웨이브 단위 저수준 갱신 자료를 뜻하며, 사용자 관점의 전체 판과 구분해 보고한다.

현재 자체 플레이 결과로 학습하는 부분은 이동 정책이다. 독립적으로 확인된 웨이브 종료/사망을 보상에 연결한다. 메뉴 분류기는 별도 검토한 정적 화면 라벨로 학습한다. 메뉴 정답 생성, 무기·빌드 선택의 장기 가치, 한 판 전체 전략까지 스스로 학습한다고 주장하지 않는다. 시작 무기 탐색은 현재 강조 위치에서 오른쪽으로 후보를 읽는 초기 규칙이며, 난이도 분류기 학습이 이 탐색을 직접 선택으로 바꾸지는 않는다.

## 실행과 중지

- `scripts/start_continuous_learning.pyw`: 숨김 실행. 로컬 플레이 조정자, 백그라운드 학습 작업자, 편집 작업자를 시작한다.
- `scripts/learning_status.py`: 현재 실행 상태, 학습 대기열/완료/거절 작업, 편집 작업자 상태 조회.
- F8 또는 `artifacts/BROTATO_STOP`: 플레이 중지. 녹화는 마감한다.
- `artifacts/LEARNING_STOP`: 백그라운드 학습 중지. `artifacts/MEDIA_STOP`: 편집 작업자 중지.
- 중지 파일은 자동 삭제하지 않는다. 재개할 때 사용자가 해당 파일을 제거한다.

현재 실행 파일은 저장된 설정/진행 상태와 이미 검증된 화면에서 이어가는 연구용 프로그램이다. 모든 캐릭터·특수 화면·모든 해금 경로가 실게임에서 검증된 완성 제품은 아니다. 인식/선택 불확실성과 반복 실패는 입력을 해제하고 `needs_review`로 남긴다. 자동 GPT 호출은 없다. 프로그램이 종료/검토 대기인 것을 계속 학습 중이라고 보고하지 않는다.

## 프로세스와 데이터

플레이: `playmodel.campaign` → `run_session` → 전투 제어. 10웨이브/시간 제한은 파일을 마감하는 구간 경계이며 캠페인 완료가 아니다. 캐릭터는 판이 끝난 뒤 바꾼다. 결과→새 판→캐릭터 그리드→무기→Nightmare 경로를 관측하고 한 번씩 키를 전송한다. 잠금 상태처럼 선택이 적용되지 않으면 해당 슬롯을 기록하고 다음 후보를 확인한다. 현재 그리드 캘리브레이션은 화면에 보이는 50개 캐릭터 슬롯이며, 전체 로스터 발견/해금 완료를 뜻하지 않는다.

학습: `playmodel.learning.worker`. SQLite 대기열에 완료된 전투를 한 번만 등록한다. 별도 저우선순위 프로세스가 원본 파일·프레임·전송 기록의 해시와 정책 버전을 검사하고 REINFORCE 후보를 만든다. 과거 에피소드를 현재 가중치에 무조건 재사용하지 않는다. 당시 고정 정책에서 파생한 후보만 생성하며, 이전에 수행한 갱신 재현 검사는 새 학습 성과와 구분한다.

숫자 유효성·확률 분포 변화·체크포인트 재읽기를 검사한다. 이는 고정 평가 게임에서의 성능 검증이 아니다. 구조 검사를 통과한 후보는 같은 원본 정책/스타일일 때만 다음 전투의 **학습 실험**에 적용한다. 제품 모델 승격·실력 향상은 별도 평가 전까지 `false`다. 배포용 모델과 섞지 않는다.

편집: `playmodel.media_worker`. 녹화 마감 후 `edit-pending.json`을 읽어 별도 폴더에 편집본·SRT·녹음 설명을 만든다. FFmpeg는 저우선순위·인코딩 2스레드로 실행한다. 게임 조작 스레드가 인코딩을 기다리지 않는다. 원본은 보존한다. 여유 공간이 10GiB 미만이면 원본을 삭제하지 않고 플레이를 중단해 공간 확보가 필요하다고 기록한다.

## 제목과 이동 보정

원본/편집본 제목에는 `Brotato__캐릭터__난이도__Endless__컨셉__무기__Wave-N__세션`을 사용한다. 값이 확인되지 않으면 `Unknown`으로 남긴다. 진입 화면의 캐릭터·무기·난이도 캡처와 결과 화면을 메타데이터에 연결한다. 상점에서 다른 무기를 추가하면 목록 갱신이 필요하며, 아직 자동 구매/모든 아이템 효과 해석은 구현 완료가 아니다.

이동은 같은 방향을 기본 200ms 유지하는 조건부 행동 마스크를 사용한다. 이동 방향 앞의 가까운 위험·목표 방향이 크게 바뀌면 즉시 전환할 수 있다. 뒤로 멀어지는 위험만으로 방향 유지가 풀리지는 않는다. 실제 사용한 마스크와 전송 행동을 학습 기록에 남기므로 가중치 학습과 로그가 어긋나지 않는다. 방향 전환 횟수/초를 보고서로 저장한다. 초기 제어 보정이며 생존율이나 학습 성능 개선을 보장하지 않는다. 전투 HUD 순간 변화는 잠깐 키를 놓고 재확인하고, 레벨업 카드 패널은 전투 장면과 분리한다.

## 남은 범위

메뉴 인식 지연과 별도 학습 분류기 적용 경계는 [빠른 메뉴 인식](brotato-fast-menu.md)을 따른다. OCR 작업자 재사용은 실행 최적화이며, 검토 자료로 학습·평가한 메뉴 분류기와 구분한다.

현재 실제 가중치 학습은 저수준 이동 정책이다. 전 무기·아이템 효과를 이해하고 최적 컨셉을 학습하는 빌드 모델, 미해금 캐릭터의 조건별 계획, 전체 로스터/특수 메뉴 검증, 고정 평가를 통한 자동 승격, 다른 게임으로의 전이는 후속 구현·검증 대상이다. 스타일 파일의 가중치와 컨셉 순회 계획을 이 기능들의 학습 완료로 부르지 않는다.
