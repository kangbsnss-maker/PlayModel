# 화면 기반 상황 판단 가중치 — 2026-09-27

사용자 요구는 이동 명령의 조합 증가가 아니라 **보이는 상황을 해석하고 목표를
선택하는 과정 자체의 학습**이다. 수십 개 규칙을 추가하는 것으로 대체하지 않는다.

## 실제 연결

최근 최대 4개 RGB 화면 → trainable CNN → 짧은 GRU → 시각 문맥 투영 →
후보별 Laya marker 표현과 결합 → 선택 확률 → 게임 adapter 실행 →
실제 전송·독립 결과 확인 → REINFORCE 갱신.

`learning/visual_decision.py`에는 게임 이름, 키 코드, 적 종류, 보상 규칙이 없다.
게임별 adapter가 관측·허용 후보·실행·결과를 제공한다. 다른 게임에서도 같은
판단 구조를 사용할 수 있지만, 다른 게임에서의 성능이나 학습 전이를 검증한 것은 아니다.

텍스트 encoder는 고정한다. CNN·GRU·투영층·Laya 판단 head는 학습 대상이다.
각 선택의 영상 창을 원본 해시, RGB 전처리 해시, 관측/이용 가능 시각과 함께 고정한다.
이전 실행/전투 epoch/메뉴의 기억은 섞지 않는다. GRU는 선택마다 고정 창을
초기 기억 0에서 재생하므로 폐기된 추론이 숨은 상태를 바꾸지 않는다.

기존 head checkpoint를 읽을 때 마지막 시각 투영을 0으로 초기화한다.
따라서 같은 텍스트 입력의 최초 logits는 기존 모델과 같다. 첫 optimizer는
투영층을 먼저 바꾸며, 이후부터 CNN·GRU에 gradient가 전달된다. 실제 갱신
보고서의 `visual_component_delta_l2`로 각 부분의 변화를 구분한다.

`playmodel.visual-goal.v1`의 체크포인트에는 시각 모듈도 함께 저장한다.
기존 `encoder_hash`는 호환성을 위해 보존하며 **텍스트 encoder만** 뜻한다.
사람의 logit bias는 신경망 가중치와 별도이고, 대상별 후보에도 행동 family의
bias를 적용한다. 사람이 말한 이유는 모델 내부 사고 과정으로 꾸미지 않는다.

## 속도와 입력 경계

학습 시 고정 텍스트 encoder 출력만 64MiB 이내 LRU에 보관한다. 학습 중인
판단 head와 시각 경로는 매번 새로 계산한다. 캐시가 없어도 결과는 같아야 한다.
전투 판단 요청 간격은 750ms에서 400ms로 변경한다. 실제 추론 완료 시각·유효
기한·최신 화면 확인은 기존 단일 writer 계약을 따른다.

입력 지연 복구 중 메뉴로 전환되면 조작권을 주지 않은 채 정확한 관측과 해제
영수증을 기록하고 화면 재확인 단계로 넘긴다. 해당 공백은 보상으로 연결하지 않는다.
STOP/F8, 대상 불일치, 부분 전송, 해제 실패는 조작 중단 조건이다.

후속 사용자 지시로 **프로그램 종료와 조작 보류를 분리**했다. STOP/F8은 사용자
중지다. 대상·전송·해제 상태가 불명확하면 조작을 보류하고 별도 read-only
supervisor가 UI 관측을 유지한다. 관측만으로 미확인 해제나 writer 종료를
확정하지 않으며, 그 supervisor에는 입력 writer와 자동 rearm 경로가 없다.
검증된 해제 후 화면 변화는 기존 두 프레임 gate를 통해 자동 재개한다.

앱의 연속 학습은 durable campaign cursor를 사용한다. 보정된 캐릭터 50슬롯,
시작 무기 위치 최대 12개, 생존/회복·균형·공격/수집 의도 세 가지를 순환한다.
모든 해금·무기가 있다는 뜻은 아니다. 요청 조합과 실제 화면에서 확인된 조합을
분리하며 완료 판만 cursor를 넘긴다. 컨셉은 모델 입력의 목표 의도이고 그 빌드
달성 사실은 아니다. 같은 판단 가중치를 유지하며 실제 조합별 기록을 남긴다.

## 아직 검증하지 않은 것

- 화면을 입력으로 학습하는 것과 나무·과실·적을 정확히 분류하는 것은 다르다.
  현재 위치 후보의 종류·소유권은 미확인이다. 녹색 후보를 과실이라고 단정하지 않는다.
- 대상별 위치 우선순위 후보는 추가했다. 실제 무기 조준 대상이나 처치를
  지정한 것으로 해석하지 않는다. 관측된 대상이 사라지면 과거 목표를 실행하지 않는다.
- 픽셀 또는 객체 소실만으로 처치·벌목·회복 보상을 만들지 않는다. 현재 보상은
  실제 전송과 연결된 검증된 웨이브 종료/사망이다.
- 검증된 나무·과실 분류, 개별 목표 달성 보상, 장기 목표 기억 및 독립 평가를
  추가해야 사용자 요청 전체의 의미 기반 목표 판단을 검증할 수 있다.

## 확인한 증거

합성 회귀: 초기 영향 0, 두 번째 이후 CNN/GRU gradient, 이미지에 따른 후보별
출력 차이, 저장 재로딩 일치, 미래/변조 프레임 거부, 학습 head 비캐싱.
실제 로컬 Laya CUDA: 기존 logits와 최초 시각 분기 logits bit-exact 일치.
동일 관측 12회 반복의 중앙값: 기존 전체 forward 135.7ms, 고정 텍스트 캐시와
시각 경로 11.6ms. 이는 반복 계산 실측이며 새 화면 추론 또는 메뉴 전체 속도,
게임 실력 향상 수치가 아니다. 실행 증거는 runtime-fix-history에 별도 기록한다.
