# ADR 0005 — Brotato 전체 판을 AI가 수행

날짜: 2026-09-27. 상태: 사용자 확정 범위. 구현 완료 상태가 아니다.

## 결정

첫 게임은 Brotato다. AI가 실행·캐릭터/시작 조건·이동·성장·상점·결과·다음 판을 담당한다. 사람 이동이나 사람이 수집한 시연을 정상 제품 흐름의 필수 조건으로 두지 않는다. 이전 뱀서류 가이드의 사람 플레이 권장은 선택적인 진단·교정 경로로 한정한다.

실행 조정자, 화면·상태 인식, 저수준 이동, 빌드/경제 선택, 독립 평가를 분리한다. 모든 보유 능력치·아이템·캐릭터 조건을 표현하되 하나의 거대 모델이 필요하다고 가정하지 않는다. 초기 규칙 정책과 실제 학습된 정책을 명시적으로 구분한다. 최적 성장·무조건 승리를 약속하지 않는다.

사용자 추가 지시에 따라 중국어 캐릭터 화면의 호버로 특성·능력치·해금 조건을 관찰하고 게임 시작까지 연결한다. 원문·증거·시점·보정 출처를 보존한다. 관측 지식을 저장하는 것, 개발자가 의미를 해석하는 것, 정책 가중치를 학습하는 것은 각각 다른 작업이다.

미해금 캐릭터 해금은 부목표다. 조건 판독·의미 검증·진행·실제 해금 확인을 구분하고 생존·진행 주목표를 임의로 희생하지 않는다. 모든 스탯을 양수로 만드는 목표로 바꾸지 않는다.

ADR 0004의 리셋 제외는 **정상 결과 화면에서 다시 시작/다음 판을 선택하는 Brotato 경로에 한해 대체**한다. 저장 데이터 초기화·계정·게임 구매·모드 설치·시스템 설정 변경은 자율 플레이 행동이 아니다. 사람 우선 단일 writer, 관측 근거, 만료된 제안 거부는 유지한다.

## 실행 순서와 승인

구현 계약은 [Brotato 계획](../games/brotato.md)을 따른다. 읽기 전용 설치 진단과 합성 상태 전환 테스트부터 실제 창/입력 adapter로 이어 간다. 상태 계약 테스트만 통과하고 자율 플레이를 구현했다고 보고하지 않는다.

시작 메뉴→한 웨이브와 성장/상점→전체 판·재시작을 각각 실제 관찰/입력/적용 기록으로 확인한다. 정상 경로는 사람 개입 없이 통과해야 한다. 인식 불명·포커스 상실·시간 초과·중지 때 입력을 해제한다. 게임·설정·규칙·정책 버전을 묶어 평가하고, 조건이 다른 실행은 분리한다.

첫 정책 학습은 실제 행동과 독립 확인된 결과로 로컬 파라미터를 갱신하고 checkpoint와 새 실행을 남길 때 인정한다. 제어 파일럿·호버/OCR·자가 출력 복제는 이 조건을 충족하지 않는다. 한 번의 갱신을 성능 향상이나 전체 자동 완성으로 보고하지 않는다.

원본 게임 파일·추출한 콘텐츠·세이브·모델은 Git에 넣지 않는다. 공식 자료와 로컬 관찰을 근거로 자체 계약·코드·검증 결과만 관리한다. 실행·학습·자체 평가는 로컬이며 GPT/API 토큰 의존성을 도입하지 않는다.
