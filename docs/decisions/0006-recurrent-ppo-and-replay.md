# ADR 0006 — 작은 재귀 PPO와 기존 화면 기록의 재사용

2026-09-27. 사용자가 [권장 주력 후보](../research/model-comparison.md)를 채택했다. 설계 채택과 구현·성능 검증 상태는 별도다.

## 결정

- 주력 구조는 공유 CNN 화면 인코더, GRU 시간 기억, 단계별 이동·후보 선택 출력, 가치 추정기를 갖는 작은 재귀 PPO다. 게임 조작·학습·평가에 GPT/API를 넣지 않는다.
- 6GB GTX 1660 SUPER를 기준으로 96×96 RGB 행동 입력, 작은 배치·짧은 학습 시퀀스부터 측정한다. 고해상도 텍스트/HUD 보조 관측은 별도로 유지하며 작은 화면에서 모든 글자를 읽는다고 가정하지 않는다.
- 보존된 과거 정책의 화면은 인코더 자기지도 사전학습에 재사용한다. 현재 단계의 재구성 손실 감소는 시각 과제 개선일 뿐 게임 실력 향상이 아니다. 다음 상태 예측은 후속 비교 대상이며 이미 구현했다고 표현하지 않는다.
- PPO에는 동일 행동 정책 버전으로 생성된 관측·합법 행동 마스크·실제 행동·행동 확률·가치·보상·종료/중단 구분이 필요하다. 과거 선형 정책의 행동을 새 정책의 PPO 자료나 BC 정답으로 바꾸지 않는다.
- 같은 새 rollout을 제한된 PPO epoch에서 사용하되 확률 변화(KL), 기울기, 수치 유효성을 점검한다. 무제한 반복이나 정책 버전이 바뀐 기록의 무보정 재사용은 금지한다.
- 신경망 변경 후에는 그 신경망으로 새 경험을 수집한다. 인코더 사전학습도 정책 버전을 바꾸므로 진행 중 판의 인코더를 수정하지 않는다.
- 원본 자료는 변경·자동 삭제하지 않는다. 고정 manifest가 선택한 원본과 해시, 출처 판, 용도를 가리킨다. 화면은 CPU uint8로 필요할 때 읽고 작은 배치만 장치로 옮긴다.
- 전체 판을 학습/평가 그룹으로 삼는다. 메뉴 평가 이미지와 연결된 이후 전투도 평가 그룹으로 보호한다. 연결 근거가 불명확한 오래된 기록은 보존하되 기본 학습 목록에서는 제외한다.
- 초기 비교용 선형 모델은 유지한다. 새 신경망의 실험 실행·수치검사 통과·정책 실력 개선·기본 모델 승격은 별도 상태다. 자동 승격은 독립된 실제 게임 평가 근거가 필요하다.
- 캡처·OCR·입력 시각은 같은 `perf_counter_ns` 시계로 기록한다. Windows에서 다른 단조 시계의 원점을 섞지 않는다. 입력 직전 신선도를 검사하고 실제 전송 시작·완료를 보존한다. 전송 후 기록 처리 지연으로 이미 보낸 입력을 기록에서 없애지 않는다.
- 구축 후 정상 반복은 로컬 실행기가 담당한다. 외부 에이전트/API 호출은 필수 경로에 없다. 오류·진행 정지는 원본과 상태 파일을 남기고 멈추며, 개발 에이전트는 수정·검증·재시작에만 관여한다. 시간 예산 만료와 사용자 중지는 오류와 구분한다.

## 검증

### 사용자 확정 목적과 실행 조건

- 적과의 접촉, 적 투사체로 인한 피해를 줄인다. 피해 감소와 생존·진행을 함께 평가한다. 단순 정지나 보상 없는 회피만으로 목표 달성을 선언하지 않는다.
- 경험치·자원 수집, 나무 등 환경과의 상호작용, 성장 선택, 무기·아이템 구매를 탐색하고 이후 전투 결과로 강화 방법을 배운다. 구매 횟수나 능력치 합계만 높이는 것을 실력 향상으로 취급하지 않는다.
- 접촉과 투사체 피해 원인이 검증되지 않았으면 `unknown`으로 남긴다. HP 감소만으로 원인을 만들지 않는다. 원인별 회피 능력은 별도 평가가 필요하다.
- 정상 실행은 에이전트 없는 로컬 프로그램 단독의 관측→행동→수집→학습→독립 평가다. 개발용 Astra 검토는 실행 의존성이 아니다. 사람의 화면 판독·승인을 매 판 요구하는 구조는 목표 미달이다.
- 한 판은 캐릭터 선택에서 실제 최종 결과까지다. 웨이브 종료는 판 종료가 아니며, 성장·상점 선택의 효과를 다음 전투에 연결한다.
- 현재 시각 사전학습과 제한된 전투 rollout 구현은 이 목적의 일부다. 접촉/투사체 구분, 강화 방법 발견, 무인 반복 학습 전체의 완료를 뜻하지 않는다.

### 통과 조건

1. 실제 GPU에서 forward/backward, 저장·재로드, 메모리, 추론 지연 측정.
2. 마스크·시간 기억 리셋·padding·burn-in·종료와 truncation·정책 버전·체크포인트 검사.
3. 기존 실제 화면 manifest 생성, 평가 판 누출 차단, 원본 변조 검출, 작은 배치 사전학습 실행.
4. 새 정책이 실제 전송한 행동으로 수집한 rollout과 독립 결과 신호를 연결. 실패·중단을 성공 보상으로 처리하지 않음.
5. 고정 비교 조건의 실제 판 평가 후 모델 교체. 학습 손실만으로 승격하지 않음.
