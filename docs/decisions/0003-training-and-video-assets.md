# ADR 0003 — 학습 기록과 영상 제작 소스의 분리

날짜2026-09-26. 상태: **설계 채택, media 기능 구현 전**.

## 결정

학습용 관측/사건 데이터와 고화질 편집 원본을 별도 저장하되 session ID·PTS↔monotonic 대응·model/evaluation ID로 연결한다. 시작 단계는 OBS 수동 녹화와 앱 marker로 충분하다. 편집에서 사용하는 소스는 pin해 자동 정리에서 보호한다.

학습은 작은 화면·정확한 입력 시각·보호 교정·정상 표본이 중요하다. 영상은 선명한 HUD·음성/게임소리·실패 전후 문맥·시청 가능한 연속성이 중요하므로 동일 보존률·코덱·파일로 억지 통합하지 않는다. 편집 오버레이/해설을 모델 학습 입력으로 돌려 넣지 않는다.

## 결과

디스크/인코딩 비용은 늘어나므로1시간 파일럿에서 각 경로의GB/h와 누락을 측정한다.30분 학습 영상의 비용을30분1080p 편집 원본 비용으로 대체 계산하지 않는다. 카메라 FPS와 정책 Hz가 다르면 원본 시간축으로 연결하며 단순 frame index 동일시를 피한다.

유튜브 결과물은 대표 실패·교정·고정 비교와 개입 표시·분모·한계를 포함한다. 게임별 게시/음원 허용 범위는 선택 뒤 확인하고 현재 업로드/수익화를 보장하지 않는다. 자동 업로드는 별도 명시적 요청과 검수 이후 기능이다.
