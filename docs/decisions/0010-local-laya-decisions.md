# ADR 0010 — 로컬 Laya 상황·선택 판단 학습

2026-09-27. 사용자 요청으로 로컬 Laya를 성장·상점의 선택 정책으로 연결한다.
원본 TypeSafe Jev와 Laya는 다른 모델이다. [Laya 코드](https://github.com/NandhaKishorM/laya),
[영어 공개 가중치](https://huggingface.co/convaiinnovations/laya)는 Apache-2.0이다.
실행 중 외부 모델 API가 필요 없다. 모델 최초 다운로드만 네트워크를 사용한다.

## 역할

검증된 메뉴 관측·마지막 확인 능력치·무기와 실제 선택지를 Laya에 전달한다.
문장을 생성하지 않고 후보별 확률을 얻는다. 학습판의 실제 선택은 이 확률에서
categorical 샘플링한다. 선택 확률은 성공 확률이 아니며 게임 도메인의 보정은 미검증이다.
현재 체력, 미확인 능력치·효과는 unknown으로 남긴다. 길이 초과 입력은 거부하며
원본 OCR이나 선택지를 몰래 절단하지 않는다.

전투 이동은 기존 CNN+GRU를 고정한다. Laya는 현재 화면 픽셀을 직접 읽거나 매 이동을
결정하지 않는다. 게임 시작·캐릭터·초기 무기 설정은 기존 검증된 시작 절차다.
Laya 도입만으로 이동 지연·OCR 지연·캡처 지연이 해결됐다고 주장하지 않는다.

## 학습

실제 메뉴 입력 전송과 독립 화면 적용 검증을 통과한 선택만 Laya 원장에 등록한다.
그 선택 뒤 독립 확인된 wave_clear(+1) 또는 death(-1)를 return으로 사용한다.
시간 할인은 초 단위 0.997. STOP·미확인·오류에는 보상을 만들지 않는다.
단일 후보 강제 선택만 있으면 가중치 학습 성과로 계산하지 않는다.

영어 encoder는 고정하고 decision head에 REINFORCE 한 step을 수행한다.
이 구현은 Laya 원래 RLCD 사전학습을 재현하는 것이 아니다. AI 선택을 정답으로
복사하는 BC도 아니다. 실제 학습 가능한 파라미터·배포 후보·전체 모델 학습을 구분한다.

actor/learner 모두 eval 모드로 dropout을 끈다. 학습 때만 gradient를 켜며 동일
토큰·옵션순서·temperature=1의 log probability를 재계산한다. 현재 temperature는
명시적인 행동 정책 설정이며 공개 체크포인트의 업무별 confidence calibration을
게임 성능 보장으로 쓰지 않는다.

최적화 전 immutable dataset manifest를 확정한다. 선택·적용 JSON 및 전후 원본
프레임 해시를 재확인한다. head 변경, encoder 불변, 유한 값, KL≤0.03, 저장·재로딩을
통과한 후보만 이후 선택에 사용한다. 이는 실력 향상 평가가 아니다. 탈락 후보도
보존하되 재개 로더에서 거부한다. 원본 base 모델은 덮어쓰지 않는다.

## 제어·자료 경계

기존 단일 입력 writer와 메뉴 identity·가격·초점·신선도·적용 검증을 유지한다.
Laya 결과 도착 뒤 화면이 오래됐으면 같은 후보가 남아 있는지 새 화면으로 검증한다.
오래된 관측으로 Enter를 허용하지 않는다. 모델 연산·학습은 숨김 별도 프로세스다.

Laya 행동에는 CNN의 hidden/value/logprob를 만들어 붙이지 않는다. 혼합 실행의
CNN 자료는 감사용이며 기존 PPO 로더가 학습 대상으로 받아서는 안 된다. 실제
학습판 전체는 train에 속한다. Laya 적응 실행과 기존 고정 source/candidate 평가의
점수를 합치지 않으며, 독립 평가를 했다고 주장하지 않는다.

현재 구현은 메뉴 선택 후 다음 전투 결과에 대한 짧은 학습이다. 장기 빌드 최적화,
회피 판단 자체의 Laya 학습, 독립적인 성능 향상 검증은 별도 작업이다.
