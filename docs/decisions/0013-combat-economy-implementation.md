# 전투 관측·빠른 회피·구매 가치 학습 연결

2026-09-28. [현황 점검](0012-combat-economy-learning-review.md)의 후속 구현.

## 실행 구조

- 전체 화면 CNN/GRU에 원본 해상도의 객체·플레이어 주변 crop 최대 4개를 추가했다.
  crop CNN과 별도 투영을 학습한다. 초기 투영은 0이며 이전 가중치는 해시로 확인해
  보존한다. 입력 영상·crop·전처리·행동 버전·원본 파일은 학습 manifest에 연결된다.
- 매 관측에서 객체 추적 시간, 상대 이동, 상단의 HP 막대 후보, 막대 감소 후보,
  녹색 후보 소실, 플레이어 HP 색상 변화, 실제 전송 후 이동 미관측을 기록한다.
  원본을 보존한 시점 쌍으로 이동 속도와 막대 감소율을 자기지도 추정하고 다음 전투에서
  사용한다. 막대 소진 예상 시간은 검증된 처치시간이나 숫자 HP가 아니다.
- 즉시 충돌 가설은 느린 전략 추론을 기다리지 않고 기존 단일 writer에 회피를 제안한다.
  덮어쓴 전략 선택에는 Laya 실행 영수증을 붙이지 않는다. 반복 이동 미관측에는 반대
  이동을 제안하지만 이를 실제 벽 위치로 확정하지 않는다. 기존 화면 가장자리 보정도 유지한다.
- 검증된 전투 종료 뒤 요약을 다음 메뉴로 전달한다. 상점 후보별 가치 예측에는 선택지와
  능력치·무기·전투 상태의 교차 특성을 사용한다. 실제 적용이 확인된 구매와 여러 웨이브의
  결과로 별도 로컬 회귀 가중치를 갱신한다. 과거 정책 선택을 최신 REINFORCE 정답으로
  재사용하지 않는다. 가치 예측은 관측 결과 예측이며 아이템의 인과 효과가 아니다.
- UI 그래프는 두 번 확인된 포커스 전이와 소요시간을 축적한다. 방향 입력 수·시간·전이
  불확실성으로 경로를 선택한다. 난이도 `0 → left → 6`은 사용자 출처 초기 가설이며 실제
  관측으로 검증한다. 저장 그래프와 최종 빠른 입력 경로 모두 Enter를 생성하지 못한다.
- `--evaluation`은 Laya·선호도·경제/이동 모델·UI 그래프를 고정한다. 완전한 판, 오류·관측
  공백 없음, 시작/끝 구성 동일성을 만족해야 평가 적격이다. 가중치 변화와 성능 향상은 별개다.

## 추가 학습 방법과 자료

1. **동작 예측**: 원본이 남은 연속 객체 관측 쌍을 회귀 자료로 사용한다. 대응 관계는
   휴리스틱이므로 투사체 종류·소유권 정답으로 쓰지 않는다.
2. **HP 관련 판단**: 지역 crop과 막대 후보/감소율/소진시간 가설을 판단망에 입력한다.
   숫자 HP 미상, HP 막대 식별 미검증 상태를 유지한다. 잘못된 막대 후보를 피해 보상으로
   승격하지 않는다. 확인된 웨이브 결과로 시각/판단 가중치를 학습한다.
3. **수집·회복·생존**: 수집 목표 선택과 위험 회피를 함께 학습하며 녹색 소실과 HUD 변화는
   특징으로만 쓴다. 개별 보석 획득·피격 원인·처치 확인은 아직 검증된 사건이 아니므로
   전용 성공 보상을 만들지 않는다. 현재 정확한 사건 라벨 수는 0으로 표시한다.
4. **빌드 시너지·장기 구매**: 가격·아이템 원문·무기·능력치·컨셉·전투 요약을 함께 사용한다.
   구매 뒤 각 웨이브의 검증된 결과를 할인해 별도 가치 회귀에 연결한다. 완전한
   효과 해석이나 최적 빌드 발견을 보장하지 않는다.
5. **경계·메뉴 운영**: 실제 이동 결과 기억과 UI 전이 그래프는 경험 기반 상태/경로 학습이다.
   이를 신경망 최적화 횟수에 더하지 않는다. 보조 가중치·그래프와 신경망 학습을 구분한다.

모든 자료와 학습 실행은 로컬이다. 실행 중 API 토큰 호출은 없다.

## 검증 범위

초기 CUDA 검사: 이전 텐서 해시 보존, 객체 분기 초기 영향 0, 합성 두 단계 뒤 객체
encoder와 투영의 실제 변화 확인. 기존 선택 376개에 추가 상태를 넣은 입력 검사에서
최대 482/512 tokens. 합성/재생 검사는 실제 게임 실력 향상 증거가 아니다.

회귀에는 가림/소실의 보상 금지, 화면 끝의 벽 단정 금지, 미래 전송 배제, 원본 해시,
상황별 구매 순위 반전, 평가 중 가중치 고정, UI Enter 주입 거부, 긴급 중재의 잘못된
Laya 학습 방지를 포함한다. 실제 학습 재개 증거는 수정 이력에 기록한다.
