# 환경·무기별 회피 관측 자료

회피 자료를 환경, 무기 관측, 능력치, 위협 궤적, 목적지 후보, 실제 전송,
후속 관측으로 분리한다. 원본 프레임과 행동 원장의 해시를 보존한다.
학습/평가 분리는 프레임이 아닌 run_id 단위다.

화면 크기는 맵 크기가 아니다. 실제 맵 크기·벽·장애물 지도는 현재 unknown이다.
카메라 이동을 맵 확장으로 누적하지 않는다. 관측 간격 초과, 해상도 변경,
추적 초기화마다 context epoch를 바꾼다. 각 관측은 화면 내 위험·수집 후보
밀도와 카메라 상태를 포함하므로 서로 다른 환경을 구분해 분석할 수 있다.

무기 이름·원문·출처는 관측 자료이며 정확한 사거리·투사체 속도·공격 주기·
관통 효과로 변환하지 않는다. 능력치는 기존 causal known mask를 통과한 값만 쓴다.
무기 이름은 마지막 관측이라는 조건으로 회귀 입력에 포함한다.

9개 이동 후보의 목적지는 화면 높이 0.08 단위 가설이다. 0.2초 위협 외삽과
거리 예측을 기록하지만 실제 도달 가능성·안전성은 unknown이다. 적/투사체 식별도
확정하지 않는다. 실제 입력 전송은 게임 반영 증명과 다르다.

검증된 전투 종료 후 인접 보존 프레임과 연속 실행 영수증만 연결한다.
5–300ms 관측 간격과 동일 epoch가 필요하다. 끊어진 자료는 censor한다.
미래 관측은 target에만 들어간다. 후속 화면의 최근접 위험 거리만 별도 로컬
회귀 모델로 학습한다. HP 불변·객체 소멸을 회피 성공이나 처치 보상으로 쓰지 않는다.
거리 회귀는 관측 상관관계이며 선택하지 않은 행동의 결과를 증명하지 않는다.
카메라 상태가 unknown이어도 후속 한 프레임 내 플레이어와 위험 후보의 상대 거리는
회귀 대상으로 쓴다. 프레임 간 월드 이동량·맵 크기를 그 값으로 추정하지 않는다.

데이터는 `artifacts/local-learning/combat-economy/evasion-*.jsonl`, 모델과
자료 해시는 기존 revision에 추가한다. 고정 평가에서는 생성·학습하지 않는다.
새 회귀 모델은 현재 행동을 직접 변경하지 않는다. 독립 평가 없이 안전한 회피
정책이라고 선언하지 않는다. 기존 Laya와 객체 신경망 학습은 계속 진행한다.

남은 범위: 실제 맵 경계 인식·카메라 보정 지도, 무기 효과 판독/검증,
투사체 식별 검증, 회피 성공 라벨, 후보 정책 독립 평가 후 제어 적용.
