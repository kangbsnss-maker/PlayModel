# ADR 0011 — 비동기 Laya 전투 전술

상태: 로컬 실행·학습·사람 교정 경계 연결 검증 완료. 독립 성능 평가 전.
ADR 0010의 메뉴 판단을 전투 전술로 확장한다.

## 결정

- Laya head가 상황별 전술 후보를 고른다. CPU 기하 실행기가 최신 프레임에서 실제 이동을 계산한다. CNN 행동 확률·가치·GRU 자료를 가짜로 만들지 않는다.
- 상대좌표 다중 프레임 추적을 사용한다. 접근·교차·선회·작고 빠른 후보는 가설이다. 적/투사체 종류, 발사 주체, 실제 무기 사거리, 현재 숫자 HP는 unknown이다.
- 관측 능력치의 출처·신뢰도·시각을 보존한다. 근접/원거리 피해량·속도·방어·회피·재생·공격 속도로 제안 거리와 후보를 조정한다. 화면 거리와 Range 값을 동일시하지 않는다.
- 선택지는 접근·후퇴·거리 유지·좌우 선회·거리 두며 이동·교차 회피를 상황별로 구성한다. 임의의 새 행동 코드를 생성하지 않는다. 의미가 정의된 후보군 안에서 동적으로 추가·제거한다.
- 단일 broker가 메뉴·전술·accept·finish 등 모든 모델 IPC를 소유한다. 전술 관측은 latest-only, 실행 증거는 유실 없는 bounded FIFO다. 포화·worker 오류는 중단한다.
- 제안값: 요청 간격 750ms, 관측 가용 시각부터 목표 TTL 1.5초. epoch·모델 버전·후보 전체 의미/설명·인과 시간을 검사한다. 선택된 후보만 검사해 표본 편향을 만들지 않는다.
- 유효한 목표가 없으면 명시적 비학습 기하 이동을 사용한다. 원본 프레임·위험 가설·능력치·선택 확률·실제 입력 receipt를 별도로 보존한다.
- 전술 acceptance는 별도 계약이다. 실제 native 전송, 기존 소유 키 유지, 중립 유지를 구분한다. 유지 입력은 이전 native 소유권 receipt와 연결한다. `game_application_verified=False`를 유지한다. 메뉴의 화면 적용 검증 요건은 낮추지 않는다.
- 전투 종료 뒤 입력 해제·writer 종료·accept drain을 거쳐 독립 clear/death로 head-only REINFORCE를 수행한다. 복구 공백·불확실 결과는 보상에서 제외한다. 전투 중 동시 optimizer는 이번 범위 밖이다.
- 이전 CNN은 별도 모드와 이미 진행 중이던 판의 제한 복구에 남는다. 새로운 Laya 학습판의 전투는 전술 경로다.

## 한계와 검증

탐지 정확도·충돌 예측·패턴 정체·최적 거리·생존 개선은 입증되지 않았다. 선택 복잡성이 커지는 것만으로 학습 효율이나 게임 속도 개선을 보장하지 않는다. 합성 회귀와 실제 제어→결과→가중치 갱신을 구분해 보고한다.

## 사람 교정과 학습 도표

사람이 수정하는 값은 고정 전술 ID별 선호도(logit bias, −2..2)다. 신경망 head 텐서와
분리해 원본·수정 이유·revision을 보존한다. 실제 정책은 `softmax(logits + bias)`이며
선택·학습 재현·KL 검사에 같은 bias를 사용한다. bias는 확률이나 배율이 아니다.

설정 저장과 모델 적용을 구분한다. 현재 전투의 분포는 고정하고, 전투 결과 학습과
원장 처리가 끝난 경계에서 새 revision을 적용한다. head와 preference hash를 함께
정책 버전에 묶고 checkpoint에 당시 설정을 보존한다. 수정 이유는 사람 출처 기록이며
독립 보상이나 BC 정답으로 자동 사용하지 않는다.

로컬 도표는 완료 판수·진행 중인 판·wave 결과를 구분한다. 유효 학습 데이터는 채택된
optimizer 보고서의 고정 manifest에 실제 사용된 판단 ID를 중복 제거해 센다.
판단 수·제어 실행 수·학습 사용 수를 섞지 않는다. 관측 상태·후보·기본 확률·사람 보정
후 확률을 판단 근거로 보여주며 모델 내부 사고를 재구성했다고 주장하지 않는다.
