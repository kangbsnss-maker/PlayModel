# 프로젝트 준비 결과

작업 기준일: 2026-09-26. 완료 범위는 **연구 검토와 개발 착수 준비(M0)**. 게임 연결·훈련된 모델·GUI 완성·영상 업로드는 후속 개발이다.

## 검토 결론

단일 게임의 반복 과제에서 사람 시연으로 BC 기준선을 만들고, 검토된 사람 교정을 누적한 뒤 독립 평가로 개선을 입증하는 프로그램으로 진행한다. Python 코어 + PySide6 데스크톱 셸, 별도 추론/학습 실행 경로를 채택했다. 장르 확장은 공통 도구를 재사용하되 게임별 어댑터·데이터·정책·평가를 구분한다. 유튜브 제작에는 별도 고화질 소스와 개입 표시·평가 근거를 연결한다.

중요 연구 분석·설계·준비 코드 독립 검토는 `gpt-6-astra`, 추론 `ultra`로 수행했다. [검토 보고서](research/review.md), [아키텍처](architecture.md), [로드맵](roadmap.md), [ADR](decisions/0001-local-desktop-and-learning-loop.md)을 참조한다.

## 보존과 정리

원본 연구 이미지 29장을 모두 시각 판독해 [페이지별 메모](research/page-notes.md)에 보존했다. 내용·수식·모델 초깃값·데이터 필드·예정 시험을 남겼으며 지면 배치의 복제본은 아니다. [출처 manifest](research/source-manifest.json)에 파일명·페이지·SHA256·바이트·실제 1414×2000 크기를 기록했다.

삭제 전 29개 원본 모두의 존재·해시·크기를 검증하고 전체 준비 검사를 통과했다. 이후 사용자 요청대로 정확한 파일 경로를 지정해 원본 29장을 삭제했다. 원본 잔여 0개. [삭제 기록](source-cleanup.json)에 대응 목록을 남겼다. 해시는 이미지 복원용 백업이 아니다.

## 실행 확인

- Python 3.12.13 가상환경과 editable 패키지 설치.
- `doctor`: GPU 6144MiB·driver560.94, Git/FFmpeg 탐지. CUDA 학습 호환성·처리량을 측정한 것은 아님.
- `validate-profile`: 의도된 초안의 미정 항목 표시, `runtime_ready=false` 유지.
- 준비 도구·보존 검증 테스트 21개 통과. 원본 누락·해시 변경·크기 불일치·삭제 기록 누락 등의 부정 대조 포함.
- 원본 29쪽 대응, 로컬 문서 링크, Git 제외/공개 유지 경계 검사 통과.
- 로컬 Git `main` 초기화, GitHub Actions 검사 정의. 원격 저장소 생성·push·원격 CI 실행은 수행하지 않음.

최종 재검증 결과는 [GATES.md](../GATES.md)에 기록한다. 로컬 전체 검사: `python scripts/verify_preparation.py`. 삭제 후 보존 상태만 검사: `python scripts/verify_preparation.py --check-cleanup`.
